Ridelore Support

Product documents: working draft

These documents describe a development build. They are not a release announcement. Product policies and store disclosures will be finalized before launch.

Email support@majesticmade.dev with the app version, device and operating system, the build you are using, and a short description. The current release candidate keeps cloud services disabled.

Protect Sensitive Records

Do not attach unredacted titles, registrations, insurance cards, VINs, receipts, keys, tokens, or backup passphrases. If a sample is necessary, remove personal and vehicle identifiers first.

Local Data and Backups

Local-only records cannot be restored by Majestic Made. Export a Ridelore backup before replacing or resetting a device, retain the passphrase separately, and test the file before relying on it.

Cloud, Links, and Purchases

The current release candidate does not provide cloud sign-in, sync, or hosted binders. These optional services remain deferred. If a later build explicitly enables them, follow that build's account, sync, and link-revocation instructions. Purchase restoration applies only when purchases are enabled in your build; use the store account that paid. Billing and refunds are handled by the store.

Export and Deletion

Use in-app export for your records. Delete local records or the app for device data. There is no cloud account to delete in the current release candidate. If a later build explicitly enables cloud services, use that build's account-deletion flow; if access is lost, contact support and complete ownership verification.
