# Majestic Made App Legal Pages

Public privacy, terms, and support pages for Majestic Made apps.

Custom domain: https://legal.majesticmade.dev/

- `almanac/` for Almanac
- `apiary/` for Apiary
- `bivy/` for Bivy
- `chat-armor/` for Chat-Armor
- `convoy/` for Convoy
- `cradle/` for Cradle
- `deep-six/` for Deep-Six
- `hook/` for Hook
- `majestic-made-hub/` for Majestic-Made-Hub
- `paws/` for Paws
- `range/` for Range
- `reach-me/` for ReachMe
- `ride-binder/` for RideBinder
- `room-proof/` for RoomProof
- `routine-cue/` for RoutineCue
- `steward/` for Steward
- `trove/` for Trove
- `use-by/` for Use By

Each app folder contains:

- `privacy/index.html`
- `terms/index.html`
- `support/index.html`

Apiary, ReachMe, RideBinder, RoutineCue, Paws, Almanac, and Use By have product-specific working
drafts based on their current implementations. Have qualified counsel review and approve them,
then reconcile them with the final release builds and store disclosure forms before launch. Other
app folders remain placeholders and must not be used for production.
